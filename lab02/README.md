# Лабораторна робота №2: Функції вищого порядку, lambda, композиція

## Варіант №9: Працівники компанії

### Мета роботи
- Опанувати функції вищого порядку (`map`, `filter`, `reduce`) та генераторні послідовності.
- Побудувати конвеєр перетворень без мутації вхідних даних.
- Застосувати функціональну композицію (`compose`), конвеєр (`pipe`) та комбінатор `juxt`.
- Виконати сортування з двома ключами та сформувати Top-N[cite: 10].
- Реалізувати статистичну `reduce`-агрегацію[cite: 10].

---

### Етапи конвеєра:
1. `normalize_names`: нормалізація імені (видалення зайвих пробілів, переведення у Title Case)[cite: 10].
2. `calculate_total_hours`: чистий підрахунок суми годин (`sum(monthly_hours)`)[cite: 10].
3. `boost_department_hours`: підсилення суми годин на коефіцієнт для вибраного відділу[cite: 10].
4. `filter_min_hours`: фільтрація працівників за мінімальним порогом годин[cite: 10].
5. `sort_by_hours_desc`: стабільне сортування (години спадно, `id` зростаюче)[cite: 10].
6. `take(top_n)`: вибірка перших N записів через `itertools.islice`[cite: 10].
7. `reduce_stats`: підсумкова агрегація (`count`, `total_hours`, `avg_hours`)[cite: 10].
