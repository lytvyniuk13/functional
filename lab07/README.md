# Лабораторна робота №7: functools та operator

## Варіант №9: Фільми та рейтинги

### 1. Мета роботи
- Опанувати практичне використання функцій вищого порядку модуля `functools`: `partial`, `reduce`, `singledispatch`, `total_ordering`[cite: 24].
- Застосувати оптимізовані інструменти модуля `operator`: `itemgetter`, `methodcaller`[cite: 24].
- Побудувати функціональний конвеєр перетворень без явної мутації та громіздких імперативних циклів[cite: 24].
- Створити поліморфний API завантаження даних із підтримкою JSON, CSV, Path, текстових файлів та списків[cite: 24].

---

### 2. Архітектурні рішення варіанта №9:
1. **Конвеєр `pipeline(value, *funcs)`**:
   - Реалізовано за допомогою `functools.reduce`[cite: 24].
   - Послідовно передає акумульоване значення крізь ланцюжок чистих перетворень[cite: 24].
2. **Часткове застосування (`functools.partial`)**:
   - `partial(is_qualified, min_year=..., min_rating=...)` фіксує параметри бізнес-фільтрації фільмів[cite: 24].
   - `partial(sorted, reverse=True)` створює готову функцію спадного сортування[cite: 24].
3. **Модуль `operator`**:
   - `itemgetter("title")`, `itemgetter("genre")` тощо замінюють ламбди для швидкого вилучення ключів[cite: 24].
   - `methodcaller("strip")` та `methodcaller("title")` виконують нормалізацію тексту[cite: 24].
4. **Поліморфний завантажувач (`@singledispatch`)**:
   - Функція `load_movies` адаптується під тип першого аргументу (`str`, `Path`, `io.TextIOBase`, `list`)[cite: 24].
   - Автоматично розпізнає формати **JSON** та **CSV** як для файлів, так і для рядків[cite: 24].
5. **Повний порядок (`@total_ordering`)**:
   - Клас `Movie` визначає методи `__eq__` та `__lt__`[cite: 24].
   - Декоратор автоматично добудовує `__le__`, `__gt__`, `__ge__`[cite: 24].
   - Порівняння відбувається за кортежем `(rating, votes, title)`[cite: 24].
