# Лабораторна робота №1: Основи функціонального програмування у Python

## Варіант №9: Прокат автомобілів

### Мета роботи
- Опанувати концепції чистоти функцій (pure functions), незмінності стану (immutability) та референтної прозорості (referential transparency).
- Реалізувати патерн **Functional Core / Imperative Shell**: відокремити математичне обчислення вартості оренди від операцій виведення результатів та системного часу.
- Застосувати типізовані функції вищого порядку (`typing.Callable`) для гнучкого налаштування бізнес-політик: знижок за тривалість оренди, страхових зборів та фільтрації замовлень.

---

### Виконання вимог варіанта №9:
- **Вхідні дані:** Клас авто (`car_class`), дні (`days`), денна ставка (`daily_rate`), статус (`status`).
- **Основне завдання:** Розраховано базову ціну (`base_price`), ступеневу знижку за тривалість (`tiered_duration_discount`) та страховий збір (`insurance_policy`).
- **Функціональні вимоги:**
  - Усі політики знижки та страхування передаються як об'єкти першого класу через `Callable`.
  - Відсутні мутації вхідних даних — функція `with_total()` генерує новий словник без модифікації переданого.
  - Жодних глобальних змінних: параметри передаються безпосередньо або через функції вищого порядку.
  - Повне відокремлення операцій I/O (виведення `print`) у файлі `app.py`.
