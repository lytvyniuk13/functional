# Лабораторна робота №5: Ліниві обчислення: генератори та itertools

## Варіант №9: Циклічний розклад

### 1. Мета роботи
- Опанувати концепції лінивих обчислень (lazy evaluation), функції-генератори з `yield` та генераторні вирази[cite: 16].
- Навчитися безпечно працювати з нескінченними послідовностями без ризику вичерпання оперативної пам'яті[cite: 16].
- Застосувати будівельні блоки модуля `itertools`: `cycle`, `count`, `zip`, `islice`, `accumulate`[cite: 16].
- Реалізувати алгоритм ковзного вікна (`sliding_window`) з O(1) оновленням на базі `collections.deque(maxlen=k)`[cite: 16].

---

### 2. Реалізація варіанта №9:
1. **`cyclic_schedule(shifts, start_day=1)`**:
   - `cycle(shift_list)` нескінченно повторює переданий цикл змін (наприклад, `["Денна", "Нічна", "Відсипний", "Вихідний"]`)[cite: 16].
   - `count(start=start_day)` генерує безперервну послідовність номерів днів `1, 2, 3, ...`[cite: 16].
   - `zip(...)` ліниво конструює іменовані кортежі `ScheduleEntry(day, shift)`[cite: 16].
2. **`take(n, it)` та `drop(n, it)`**: універсальні функції для безпечного відбору або пропуску фіксованої кількості записів над нескінченними потоками через `itertools.islice`[cite: 16].
3. **`sliding_window(it, k)`**: ефективна лінива генерація вікон фіксованого розміру без попередньої матеріалізації списків[cite: 16].
4. **`accumulate`**: обчислення префіксної статистики кількості фактично відпрацьованих днів[cite: 16].

---

### 3. Перевірка лінивості обчислень
У тесті `test_laziness_evaluation` використовується генератор-шпигун (`spy_generator`), який веде облік кількості звернень:
- Доки генератор обгорнуто в `islice`, лічильник дорівнює `0`[cite: 16].
- Після запиту `take(5, ...)` лічильник дорівнює строго `5`[cite: 16].
Це доводить відсутність жадібного (eager) завантаження нескінченного джерела[cite: 16].
